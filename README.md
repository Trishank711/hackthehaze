## 🌍 Project Overview
<img src="https://images.unsplash.com/photo-1603784558471-29d1a15d7b89?auto=format&fit=crop&w=1200&q=80" width="100%" />

**HackTheHaze** is a ward-level air quality monitoring system designed to expose **micro-level AQI variations across Delhi**.

> City-wide AQI hides the truth.  
> **Wards don’t breathe the same air.**

---

## ❓ Why HackTheHaze?
<img src="https://images.unsplash.com/photo-1604537529428-15bcbeecfe4d?auto=format&fit=crop&w=1200&q=80" width="100%" />

- AQI differs **street-to-street**
- Central AQI numbers lack local relevance
- Health risks depend on **where you live**, not city averages

This project aims to **visualize pollution where it actually happens**.
